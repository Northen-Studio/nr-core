# Changelog

## 1.0.0 — 15 November 2026

Initial Northen Studio Core release implementation.

- Add event-driven ESX Legacy, QBCore, Qbox, custom and standalone selection.
- Reject ambiguous automatic detection; support explicit selection and recovery.
- Add independent notification adapters, native fallback and targeted server API.
- Add ox_lib and upstream progressbar progress with cancellation, overlap checks
  and watchdog cleanup; include replaceable custom examples.
- Expose normalised player snapshots with strict field whitelisting.
- Add configuration validation, structured logging, startup branding and static
  licence metadata with no online validation or restrictions.
- Include ACE-restricted example, British English documentation and Lua 5.4 tests.

Live FXServer visual, network and framework compatibility checks remain pending;
see docs/testing.md before public release.
